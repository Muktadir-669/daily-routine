# Daily Routine 

Welcome to the **Daily Routine** project! This repository is designed to help maintain a structured, disciplined, and productive life.

## 📌 Features
- **Daily Task Tracker:** Keep track of your daily goals and daily schedule.
- **Clean UI:** Simple and user-friendly interface built with HTML/CSS.
- **Automated CI:** Integrated Jekyll CI workflow via Docker to ensure clean builds.
